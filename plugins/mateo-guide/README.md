# Mateo Guide MCP

Primer plugin experimental para The Intelligence Ahead. Cuatro herramientas de solo lectura basadas en las 124 páginas originales de Mateo y el Algoritmo. Servidor MCP Streamable HTTP con el SDK oficial, sin autenticar al usuario, sin lectura de datos privados y sin actuar sobre cuentas externas.

Instalación: npm install, npm test, npm start. Endpoint local: http://localhost:8787/mcp. Despliegue Vercel aislado: rootDirectory plugins/mateo-guide, endpoint /mcp.

No publicado ni aprobado todavía en el directorio de OpenAI. Se necesitarán verificación de desarrollador, identidad/dominio, documentación y pruebas con clientes MCP antes de envío para revisión.
